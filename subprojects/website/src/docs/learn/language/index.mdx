# Semantifyr Language

The Semantifyr Language is Semantifyr's language for semantics: the semantic libraries are written in it, and so is every model Semantifyr verifies, by hand or as a [frontend](../frontends/index.mdx)'s translation onto its language's library.

It is written by the author of a language's semantic library, as the frontends' authors are, and by someone whose language has no frontend, who writes the library and the models directly.

- [Specification](specification/index.md): look a construct up, one construct a page.
- [Lessons](lessons/index.md): learn the language on a junction of traffic lights, lesson by lesson, each step running in Live.
- [Compilation](compilation/index.mdx): see how the compiler turns a model into the transition system a backend checks, in three phases.
