# Semantifyr Language

The Semantifyr Language is the language in which Semantifyr defines semantics. A language's semantics is written once, as a [semantic library](lessons/semantic-libraries.md), and every model of that language becomes a Semantifyr model on the library, which Semantifyr compiles and verifies. The [frontends](../frontends/index.mdx) work this way: the SysML v2 and Gamma libraries are written in it, and each frontend maps a model onto its library.

Write in it to define the semantics of a language of your own, or to model a system directly.

- [Lessons](lessons/index.md): learn the language on a junction of traffic lights, building each step in Live.
- [Language Reference](reference/index.md): look up a construct, one construct a page.
- [Compilation](compilation/index.mdx): see how the compiler turns a model into the flat model a backend checks.
