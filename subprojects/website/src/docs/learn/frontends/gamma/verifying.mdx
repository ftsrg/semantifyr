# Verifying Gamma Models

## In Live

Open [Live](https://live.semantifyr.org), pick one of its Gamma examples in the toolbar or write your own model, and press **Verify all**.

## On Your Machine

```bash
semantifyr-gamma verify model.gamma
```

In VS Code, see [Try in VS Code](../../start/vscode.md). To install either, see [Install](../../start/install.md).

## Writing a Verification Case

A verification case names its component and holds its property: `AG` states that every reachable state satisfies a condition, and `EF` that some run reaches one.
