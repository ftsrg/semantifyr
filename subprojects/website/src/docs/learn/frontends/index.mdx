# Frontends

A frontend brings an engineering language to Semantifyr: its translation into OXSTS, its semantic library and its traces. A frontend writes the [witness](../oxsts/language/library-and-output/inlined-models.md#witnesses) of a case back as its trace, what a reader reads of the case: the steps of the witness in the language of the model, which for a failed `AG` case model checkers call a counterexample.

Currently implemented frontends: [SysML v2](sysml-v2/index.mdx), [Gamma](gamma/index.mdx).
