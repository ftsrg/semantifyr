# Frontends

A frontend brings an engineering language to Semantifyr: it translates a model into a Semantifyr model on the language's semantic library. Semantifyr has frontends for:

- [SysML v2](sysml-v2/index.mdx), OMG's Systems Modeling Language.
- [Gamma](gamma/index.mdx), the statechart composition language of the BME [Critical Systems Research Group](https://ftsrg.mit.bme.hu/en/).
