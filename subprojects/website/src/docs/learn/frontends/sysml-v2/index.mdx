# SysML v2

The SysML v2 frontend, one of Semantifyr's currently implemented frontends, verifies models of OMG's Systems Modeling Language. It translates a model and its verification cases into a Semantifyr model on the SysML v2 semantic library, with a fork of SysIDE, and writes the trace of a case as a SysML v2 model that refines the model it came from.

- [Verifying SysML v2 Models](verifying.md): a room with a switch and a lamp, verified in Live and with `semantifyr-sysml`.
- [Supported Language](supported.mdx): the constructs the translator reads, each with its outcome, what the library assumes of a model's meaning, and what a verdict covers.
- [Traces](traces.mdx): the form of a trace.
