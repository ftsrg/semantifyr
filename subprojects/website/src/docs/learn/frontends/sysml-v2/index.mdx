# SysML v2

The SysML v2 frontend verifies models of OMG's [Systems Modeling Language](https://www.omg.org/sysml/sysmlv2/). It translates a model and its verification cases into a Semantifyr model on the SysML v2 semantic library, using the SysML v2 language server [sysml-2ls](https://github.com/arminzavada/sysml-2ls).

- [Verifying SysML v2 Models](verifying.md): verify a model in Live and on your machine.
- [Lesson: A Switch and a Lamp](lesson.md): build and verify a small model step by step.
- [Language Support](language-support.mdx): the models we support.
- [Semantic Decisions](semantic-decisions.mdx): the semantics we give them.
- [Traces](traces.mdx): how execution traces are represented in SysML v2.
