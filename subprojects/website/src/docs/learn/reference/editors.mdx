# Editor Settings

The settings of the [VS Code extension](../tools/vscode.md), as its manifest declares them:

<VscodeSettings manifest={extension} />

The extension sends the settings to the OXSTS and the Gamma language server when they start and again whenever one changes, so a change applies from the next verification without a restart; `semantifyr.verification.autoValidate` and `semantifyr.verification.validationPortfolio` stay in the extension, which asks for the validation. A portfolio is named by its id, as [the portfolios](cli/portfolios.mdx) list them. The artifacts are laid out as [Artifacts](artifacts/index.mdx) describes: under `workspace` each case directory is in the workspace's `.artifacts/` folder, which the *Testing* view leaves out, and under `temporary` in a folder of the language server's own, which it deletes when it exits, so the witnesses of earlier runs are gone after VS Code restarts.
