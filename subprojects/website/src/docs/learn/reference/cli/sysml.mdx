# SysML v2 on the Command Line

`semantifyr-sysml` verifies SysML v2 models. Its distribution, `semantifyr-sysml-<version>.zip`, carries Theta, the SysML v2 semantic library in `libraries/sysmlv2` and the [tutorial](../../sysml-v2/tutorial.md) model as `models/smoke/room.sysml`. It translates a model to OXSTS with the bundled SysIDE fork, which runs on Node.js, so it needs `node` (<NodeVersion /> or newer) on `PATH`; without it, translating fails with exit code 4 and a message naming `node`. The translator reads every `.sysml` and `.kerml` file below the model's directory as the model's workspace, so keep other models and the artifact directory out of that directory. Translations are cached under `~/.semantifyr/sysml-cache`, keyed by the model and its workspace ([Folders](index.mdx#folders)). [Verifying on the Command Line](../../tools/command-line.md) walks through a run.

## `verify`

<CodeBlock language="text">{verify}</CodeBlock>

`verify` translates the model and verifies its cases with the options, output and [exit codes](index.mdx#exit-codes) of `semantifyr verify`. The case names start with `semantifyr::sysml::model`, the package the translator gives every model. The translated model stays under the artifact directory, and for each case with a witness `verify` writes the witness as a SysML v2 model, `trace.sysml`, next to the case's `report.json` ([Artifacts](../artifacts/index.mdx), [SysML v2 traces](../artifacts/sysml-trace.mdx)); a witness the generator cannot express keeps its verdict, gets no `trace.sysml` and a warning in the log.

The translation is verified on top of the bundled SysML v2 semantic library, the state-level library in `libraries/sysmlv2`. `--library` loads OXSTS files in addition to it and does not replace it.

## `compile`

<CodeBlock language="text">{compile}</CodeBlock>

`compile` writes the OXSTS translation of the model to `--output`, by default next to the model with the `.oxsts` extension, and the name map from the model's elements to the OXSTS beside it with the `.names.json` extension. A construct the translator refuses is an error at its line and no OXSTS is written; a warning is printed and the translation written ([What Is Supported](../../sysml-v2/supported.mdx)). `semantifyr` verifies it together with that library: `semantifyr verify -l <semantifyr-sysml distribution>/libraries/sysmlv2 room.oxsts`.
