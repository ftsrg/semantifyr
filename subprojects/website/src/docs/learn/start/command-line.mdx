# Try in the Command Line

`semantifyr` verifies the cases of a Semantifyr model on your machine, with every installed backend, by hand or in scripts and CI. This page verifies the level crossing in the Semantifyr Language. [Install](install.md#the-command-line) builds the command, `bin/semantifyr` of its distribution, and [Command Line](../reference/command-line.mdx) lists its options; a SysML v2 or a Gamma model is verified by its frontend's launcher, [`semantifyr-sysml`](../frontends/sysml-v2/verifying.md#verifying-locally) or [`semantifyr-gamma`](../frontends/gamma/verifying.mdx#verifying-locally).

## The Model

Save the model as `level-crossing.semantifyr` in an empty directory, `/tmp/level-crossing` on this page:

<CodeBlock language="oxsts" title="level-crossing.semantifyr">{levelCrossing.text}</CodeBlock>

In that directory, list its cases:

```bash
semantifyr list level-crossing.semantifyr
```

```text
Found 2 verification case(s):
  example::levelcrossing::BarrierDownWhileTrainInCrossing
  example::levelcrossing::TwoTrainsCanBeInTheCrossing
```

## Verifying

Verify every case, with the artifacts in `artifacts/`:

```bash
semantifyr verify level-crossing.semantifyr --artifact-directory artifacts
```

```text
Verifying example::levelcrossing::BarrierDownWhileTrainInCrossing ...
  FAILED (2.203420429s)
  report: /tmp/level-crossing/artifacts/level-crossing.example.levelcrossing.BarrierDownWhileTr-e3f8b4e8/report.json
Verifying example::levelcrossing::TwoTrainsCanBeInTheCrossing ...
  PASSED (500.711637ms)
  report: /tmp/level-crossing/artifacts/level-crossing.example.levelcrossing.TwoTrainsCanBeInTheCrossing/report.json
```

Each case ran on the default `smart` portfolio, and the command exited with status 5, since a case failed ([exit codes](../reference/command-line.mdx#exit-codes)). The cases end with these verdicts:

## The Witness

The failed case's directory, its name cut short with a hash as [the case directory](../reference/artifacts.mdx#the-case-directory) gives, holds a directory for each [stage](../backends/portfolios-and-verdicts.mdx#stages) of `smart` that ran, on a machine with all four backends and fewer processors than their sixteen configurations, here the first stage alone:

```bash
ls -1 artifacts/level-crossing.example.levelcrossing.BarrierDownWhileTr-e3f8b4e8
```

```text
first
mapping.json
pipeline
report.json
witness.semantifyr
```

Beside the compiled models under `pipeline/`, each backend run has a directory of its own in its stage's directory, such as `first/theta-bmc`; `report.json` holds the verdict and the run that breaks the case, and `witness.semantifyr` is the [witness](../language/specification/library-and-output/inlined-models.md#witnesses) derived from it. [Artifacts](../reference/artifacts.mdx) describes each file.
