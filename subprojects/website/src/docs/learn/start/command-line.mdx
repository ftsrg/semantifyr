# Try in the Command Line

The command-line launchers verify the cases of a model on your machine: `semantifyr` for Semantifyr models, `semantifyr-sysml` for SysML v2, and `semantifyr-gamma` for Gamma. To install them, see [Install](install.md#the-command-line).

A Semantifyr model:

```bash
semantifyr verify model.semantifyr
```

A SysML v2 model:

```bash
semantifyr-sysml verify model.sysml
```

A Gamma model:

```bash
semantifyr-gamma verify model.gamma
```

Each case prints its verdict and where its report and witness are written; see [Artifacts](../backends/artifacts.mdx). `--help` after any command lists its options.
