# Command Line

The `semantifyr` command lists, compiles and verifies the verification cases of OXSTS models. Install it from the release zip ([Getting Started](../getting-started.md#option-d-install-the-command-line-interface-for-scripts-and-ci)) or build it from source with `./gradlew :semantifyr-cli:installDist`; the launcher is `subprojects/semantifyr-cli/build/install/semantifyr/bin/semantifyr`. It needs a Java 25 runtime and at least one verification backend.

<CodeBlock language="text">{help}</CodeBlock>

:::note
Pass directories as model and library paths: today the commands reject a path to a single `.oxsts` file despite their help text. A directory is searched recursively for `.oxsts` files, so put a model you want to verify alone in its own directory.
:::
