# Command Line

The `semantifyr` command lists, compiles and verifies the verification cases of OXSTS models. Build it from source with `./gradlew :semantifyr-cli:installDist`; the launcher is `subprojects/semantifyr-cli/build/install/semantifyr/bin/semantifyr`. It needs a Java 25 runtime and at least one verification backend.
