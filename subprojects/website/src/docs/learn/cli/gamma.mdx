# Gamma on the Command Line

`semantifyr-gamma` verifies Gamma models (`.gamma` files, the language of the in-tree Gamma frontend, a simplified Gamma): statecharts, their composition and their verification cases. It compiles a model to OXSTS on top of the bundled Gamma semantic library. Its distribution, `semantifyr-gamma-<version>.zip`, carries Theta, the library in `libraries/gamma` and the example model `models/smoke/Simple.gamma`.

## `verify`

<CodeBlock language="text">{verify}</CodeBlock>

`verify` compiles the model and verifies its cases with the options, output and [exit codes](index.mdx#exit-codes) of `semantifyr verify`. A case is named by its Gamma qualified name, such as `Simple.WorkerStatechartIdleReachable`; without `--case-name`, `verify` verifies every case of the model. For each case with a witness, `verify` writes the witness as a Gamma execution trace, `trace.gamma`, next to the case's `report.json` ([Artifacts](artifacts.mdx), [Gamma traces](gamma-trace.mdx)).

## `compile`

<CodeBlock language="text">{compile}</CodeBlock>

`compile` writes the OXSTS model of a Gamma model to `--output`, by default next to the model with the `.oxsts` extension. `semantifyr` verifies it together with that library: `semantifyr verify -l <semantifyr-gamma distribution>/libraries/gamma Simple.oxsts`.
