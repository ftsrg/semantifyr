# Gamma on the Command Line

`semantifyr-gamma` verifies Gamma models (`.gamma` or `.gcd` files, the language of the in-tree Gamma frontend, a [sub-language of Gamma](../gamma.mdx) in Gamma's syntax): statecharts, their composition and their verification cases. A verification case names its component and holds its property, `verification case IdleReachable of System { EF state worker.Main.Idle }`. The Gamma models in the model's directory are its workspace, in which its imports resolve; `--workspace <directory>` makes the `.gamma` and `.gcd` files of that directory, recursively, the workspace instead, for a model that imports from another directory. It compiles a model to OXSTS on top of the bundled Gamma semantic library. Its distribution, `semantifyr-gamma-<version>.zip`, carries Theta, the library in `libraries/gamma` and the example model `models/smoke/Simple.gamma`.

## `verify`

<CodeBlock language="text">{verify}</CodeBlock>

`verify` compiles the model and verifies its cases with the options, output and [exit codes](index.mdx#exit-codes) of `semantifyr verify`. A case is named by its Gamma qualified name, such as `Simple.WorkerStatechartIdleReachable`; without `--case-name`, `verify` verifies every case of the model. Under the artifact directory, each case gets a directory named after it, holding the compiled model `model.oxsts`, one OXSTS package per imported Gamma package under `imports/`, and the verification artifacts under `verification/`. For each case with a witness, `verify` writes the witness as a Gamma execution trace, `trace.get`, next to the case's `report.json` ([Gamma traces](../../develop/gamma-trace.md)).

## `compile`

<CodeBlock language="text">{compile}</CodeBlock>

`compile` writes the OXSTS model of a Gamma model to `--output`, by default next to the model with the `.oxsts` extension. Every Gamma name is written with a leading underscore, `Main` as `_Main`, so none equals a library member or an OXSTS keyword. `semantifyr` verifies it together with that library: `semantifyr verify -l <semantifyr-gamma distribution>/libraries/gamma Simple.oxsts`.
