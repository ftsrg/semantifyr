# OXSTS

OXSTS is Semantifyr's language for semantics: the semantic libraries are written in it, and so is every model Semantifyr verifies, by hand or as a [frontend](../frontends/index.mdx)'s translation onto its language's library.

It is written by the author of a language's semantic library, as the frontends' authors are, and by someone whose language has no frontend, who writes the library and the models directly.

- [Lessons](lessons/index.md): learn OXSTS on a traffic light, level by level, each step running in Live.
- [Language](language/index.md): look a construct up, one construct a page.
- [Compilation](compilation/index.mdx): see how the compiler turns a model into the transition system a backend checks, in three phases.
- [On the Command Line](command-line.mdx): verify an OXSTS model with `semantifyr`.
