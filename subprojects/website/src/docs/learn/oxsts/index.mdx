# OXSTS

OXSTS is Semantifyr's language for semantics. The semantic library of a language is written in it, and every model Semantifyr verifies is an OXSTS model that instantiates the classes of such a library, written by hand or translated by a [frontend](../frontends/index.mdx).

It is written by whoever gives a language its semantics, a frontend's semantic library among them, and by whoever verifies the models of a language without a frontend, who writes the library and the models in OXSTS directly. A model in SysML v2 or Gamma needs none of it written by hand.
