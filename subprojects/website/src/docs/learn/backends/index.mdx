# Backends

A backend is a model checker that verifies the [transition system](../language/compilation/index.mdx) a verification case compiles to. Semantifyr runs the backends in [portfolios](portfolios-and-verdicts.mdx), which decide the verdict from the answers they trust.

- [Theta](theta.mdx): needs `theta-xsts-cli` on `PATH`, or Docker. Its verdicts are exact on models whose clock tests are closed.
- [nuXmv](nuxmv.mdx): needs `nuXmv` on `PATH`. Its verdicts are exact.
- [Spin](spin.mdx): needs `spin` and `gcc` on `PATH`. A trace it finds is trusted, a proof is not.
- [Uppaal](uppaal.mdx): needs `verifyta` on `PATH`. A trace it finds is trusted, a proof only from its `over-approximation` configuration.

A backend that cannot transform a model answers Not supported and names each construct it refuses. Each backend's page lists them.
