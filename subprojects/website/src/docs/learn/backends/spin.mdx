# Spin

[Spin](https://spinroot.com/) verifies the Promela translation of a case. It computes with 32-bit integers and havocs an integer only among candidate values, so it is under-approximating: a trace it finds is trusted, a proof is not. Before it runs, it reports a case Not supported when the case holds a construct of the table, naming each construct, or the variable it concerns, and its source line. The table is generated from Spin's capability check, so it describes the current build.
