# Theta

[Theta](https://github.com/ftsrg/theta) verifies the XSTS translation of a case with unbounded integers, and on a model whose clock tests are all closed the verdicts of its configurations are exact, so a portfolio trusts every one of them there, except those of `chc`. That configuration is Horn solving: Theta encodes the case as constrained Horn clauses and solves them with its bundled Z3. It reports a violation without a trace, so a portfolio trusts it only for a verdict that needs no witness, an invariant that holds or a state that is unreachable; a violation it reports is not trusted and carries no witness. It needs `theta-xsts-cli` on `PATH`, or Docker. It realizes the [wait before every main step](../language/specification/classes-and-behaviour/time.md#the-wait-before-a-step) as a whole delay, a whole amount of time that every clock advances by. When every clock test of the model is [closed](../language/specification/classes-and-behaviour/time.md#closed-clock-tests), a run with whole delays reaches every state dense time does; when one is not, a step that waits a fraction can reach a state no whole delay does, so the run declares itself under-approximating: a portfolio trusts a trace it finds, which is a run of the model, and not a proof. Before it runs, it reports a case Not supported when the case holds a construct listed below, naming each construct and its source line.

## What the backend refuses

- Variables of type `real`, `string` or `any`: XSTS has integer, boolean and enumeration variables only.
- Real literals: XSTS has no real numbers.
- String literals: XSTS has no strings.
- Array literals: the backend receives arrays split into one variable per slot and has no form for an array value.
- For-operations over anything but a range: an XSTS loop runs over an integer range.
- Clock tests that are not closed, in `chc` alone: whole delays under-approximate such a model, and Horn solving gives its verdicts without a trace.
- Clocks bounded at the largest 32-bit integer: a whole delay saturates a clock one above its largest bound, and an XSTS integer literal holds no value above 2<sup>31</sup> - 1.
