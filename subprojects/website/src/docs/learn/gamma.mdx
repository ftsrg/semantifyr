# Gamma

Semantifyr is a framework for the execution semantics of engineering languages; Gamma, the statechart composition language of the BME Fault Tolerant Systems Research Group, is one of its frontends, beside SysML v2. The Gamma frontend maps a sub-language of Gamma, written in Gamma's syntax, one to one into a semantic library written in OXSTS. The library holds Gamma's execution semantics, and each of Gamma's semantic variation points is a variant of the library. Small models, one per feature, check the library on every change, and the models of Gamma's own tests check its coverage every night; each verdict is the one Gamma gives, except where a difference below is declared. A model that uses a construct outside the sub-language is rejected.

The [command line](cli/gamma.mdx) verifies Gamma models, and a witness is written as a [Gamma execution trace](../develop/gamma-trace.md).
