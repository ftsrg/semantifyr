# Where to Start

**Semantifyr** is a framework to declaratively define the semantics of engineering modeling languages. Where you start depends on what you want to do.

- **Try it without installing anything:** [Try in the Browser](start/live/index.md) verifies a model in Semantifyr Live.
- **Verify a SysML v2 model:** see [Verifying SysML v2 Models](frontends/sysml-v2/verifying.md), or the [lesson](frontends/sysml-v2/lesson.md) that builds a room with a switch and a lamp.
- **Verify a Gamma model:** [Verifying Gamma Models](frontends/gamma/verifying.mdx) walks through a level crossing.
- **Define the semantics of your own language:** the [lessons](language/lessons/index.md) build a semantic library step by step, and the [specification](language/specification/index.md) defines the Semantifyr Language.
- **Work on your own machine:** [Install](start/install.md) the VS Code extension or the command-line launchers.
