# What Is Semantifyr

**Semantifyr** is a framework to support the declarative definition of engineering model semantics. Where a verification tool usually translates each engineering language to a model checker by a translator of its own, Semantifyr has the execution semantics of a language written once, as a **semantic library** in its own language, the Semantifyr Language, and verifies every model of the language as an instance of that library. The same library verifies many models, a language can have variants of its library, and the model checkers, the backends, never need to know the engineering language.

## Overview

<Architecture />

A [frontend](frontends/index.mdx) translates a model of its language, with the verification cases written in it, into a Semantifyr model, which instantiates the classes of the language's semantic library. Semantifyr compiles each case of it into a formal model, a transition system, in [three phases](language/compilation/index.mdx), and a [portfolio](backends/portfolios-and-verdicts.mdx) hands that to the [backends](backends/index.mdx), Theta, nuXmv, Spin and Uppaal. The verdict comes back, and where it rests on a run the backend found, the run comes back too: as the formal trace, back-annotated into a trace of the Semantifyr model, and turned by the frontend into a trace in the language of the model.
