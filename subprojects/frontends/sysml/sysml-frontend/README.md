# SysML v2 Semantics

This subproject contains the modelled SysML v2 semantic library (./Library), a variant library (./TopDownLibrary), and the automated verification of the used test models (./TestModels).

Running the tests: `./gradlew :sysmlv2-semantics:verificationTest` runs the verification suite.
