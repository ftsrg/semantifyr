# SysML v2 wrapper

This module clones [the SysIDE fork](https://github.com/arminzavada/sysml-2ls) into `sysml-2ls` at the `sysmlCommit` of [build.gradle.kts](build.gradle.kts) and builds the SysML v2 command line and language server from it.

Do not edit `sysml-2ls` here: change the fork in its own repository, then bump `sysmlCommit`.
